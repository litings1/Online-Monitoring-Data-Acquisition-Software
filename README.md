# 在线监测数据采集软件

> 面向环境在线监测系统的数据采集、设备通信与协议解析软件  
> 支持多仪器接入、统一协议抽象、实时数据采集与存储

---

## 📌 项目简介

本项目用于 **环境在线监测系统**，实现对多种现场仪器的数据采集、协议解析与统一管理。

特点：
- 🧠 软件 / 仪器 / 协议 解耦设计
- 🔌 支持多种通信方式（TCP / 串口 / Modbus / 自定义协议）
- 📊 实时数据采集、缓存与上报
- 🛠 适用于 VOC、气体分析、离子色谱等在线仪器
